# Kubernetes Task Manager

A full-stack task management application built to demonstrate
containerization, Kubernetes orchestration, and DevOps practices.

## Architecture

- Frontend: Nuxt.js
- Backend: NestJS
- Database: PostgreSQL
- Containers: Docker
- Orchestration: Kubernetes
- Local Environment: Colima + Minikube
- Production Environment: K3s on VPS (planned)
- CI/CD: GitHub Actions
- Container Registry: GitHub Container Registry (GHCR)
- Monitoring: Prometheus + Grafana

## Environments

- Local Development
- Staging: staging-project-1
- Production: prod-project-1

## Project Structure

- frontend/ - Nuxt.js application
- backend/ - NestJS API
- database/ - Database initialization and scripts
- docker/ - Docker-related configuration
- kubernetes/ - Kubernetes manifests
- helm/ - Helm charts
- monitoring/ - Monitoring configuration
- .github/workflows/ - CI/CD workflows
